# Source provenance

`TuyaConfig.Core` links this repository's existing `BK7231Flasher/Utils/TuyaConfig.cs`. The linked file is pinned byte-for-byte to `openshwprojects/BK7231GUIFlashTool` commit `412a42a31ff9d03cd9c0d144ae1197e3352b78b5`, path `BK7231Flasher/Utils/TuyaConfig.cs`.

`TuyaConfig.Core/MiscUtils.cs` retains the helper semantics used by that extractor. `Compatibility.cs`, `TuyaDumpExtractor.cs`, the Android UI, test harness and packaging workflow are Android-port adapter code.

No claim is made that the Android wrapper is an official BK7231 Easy Flasher release.
